# Changelog: Exploratory Evaluation Discipline

## [0.1.0] - 2026-07-21

### Added
- Initial version of exploratory-eval-discipline.
- Core instructions for honest small-sample method comparison: pre-registered falsifiers,
  separated LOSO development vs sealed held-out splits, must-beat-the-simplest-baseline gate,
  leakage/trivial-cue checks, exploratory reporting with split/n/caveat, and the label-ceiling
  hypothesis when methods plateau together.
- Examples covering pre-registered falsifiers, dev-vs-held-out with baseline comparison, and
  honest small-sample reporting.
- Test prompts for honest comparison setup, over-claim avoidance, leakage detection, held-out
  protection, the label-ceiling case, honest write-up, and the baseline requirement.
