## [0.1.0] - 2026-08-04

### Added
- Initial skill: one artifact, one generator, one source of truth.
- `figN_`/`tabN_` generator naming tied to the manuscript's own figure and table numbers.
- Single configured source-of-truth results directory and a single shared data layer.
- Machine-checkable manifest with a `check` command as the authority over prose docs.
- Complete-removal rule for dropped experiments, and documented silent failure modes.
